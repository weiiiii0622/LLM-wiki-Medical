# Nocturnal penile tumescence test, NPT (夜間陰莖勃起監測)

## Summary

評估睡眠中自然勃起以區分 psychogenic 與 organic erectile dysfunction。 本頁已整合至 `醫(五)第5冊泌尿`；若同一 topic 也出現在舊來源，來源與重點會保留並合併。
