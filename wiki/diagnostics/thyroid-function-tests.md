# Thyroid function tests (甲狀腺功能檢查)

## Summary

TSH、free T4/T3 是甲狀腺亢進或低下的核心檢查。 本頁已整合至 `醫(三)第2冊肝內新陳代謝`；若同一 topic 也出現在舊來源，來源與重點會保留並合併。

## Key Details From Sources

- 1. 甲狀腺促進素 (Thyroid Stimulating Hormone, TSH): - (1) 與其他腦下垂體分泌的荷爾蒙一樣,都是脈動性分泌(Pulsatile secretion),但半衰期較長,因此單點量測足以提供臨床資訊。(Harrison 2225) - (2) TSH 為偵測 Primary hypo/hyperthyroidism 最敏感的方法。 Source: [[sources/med3-book2-ch11|乙、甲狀腺疾病]].
- #### 4. T4 → T3 · T4 v.s. free T4 : Source: [[sources/med3-book2-ch11|乙、甲狀腺疾病]].
- (1) 甲狀腺每天製造較多的 T4, T4 是 T3 的前驅物 (Precursor), T4 在肝、腦、脂肪組織 (Brown fat)等被轉為 T3, 進而與位在核內基因上的 nuclear thyroid hormone receptor 結合, 結合的親和力 T3 較 T4 強 (T3 的強度較強)。 (Harrison 2227) Source: [[sources/med3-book2-ch11|乙、甲狀腺疾病]].
