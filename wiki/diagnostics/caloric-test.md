# Caloric test (溫差試驗)

## Summary

Caloric test 以冷熱刺激外耳道評估水平半規管與前庭眼反射功能。 本頁已整合至 `醫(六)第4冊麻醉耳鼻喉`；若同一 topic 也出現在舊來源，來源與重點會保留並合併。

## Key Details From Sources

- #### C. 前庭功能檢查一溫差試驗 (Caloric test) Source: 醫(六)第4冊麻醉耳鼻喉_第二篇、耳鼻喉科_甲、耳科 Page 133-184.
