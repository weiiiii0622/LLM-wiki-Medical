# Cover-uncover test (遮蓋試驗)

## Summary

遮蓋試驗區分 phoria/tropia 並評估斜視方向與大小。 本頁已整合至 `醫(六)第2冊眼科`；若同一 topic 也出現在舊來源，來源與重點會保留並合併。

## Key Details From Sources

- ...prism reflection test: 直接在把稜鏡放在斜視的眼前,以光源同時 照射兩眼,調整稜鏡度數直到反光點落在瞳孔中央。因為 Krimsky test 不考 慮隱斜視,時常低估了偏移的真實角度。 - c. 遮蓋-去遮蓋測試 (cover-uncover test): - (a) 遮蓋測試,值測顯性的偏移(斜視 tropia):請病人注視正前方物體,並 遮蓋住一眼,觀察另一隻眼是否有移動。若有移動則表示有斜視;若無 移動可用去遮蓋測試,觀察是否有隱斜視。 Source: 醫(六)第2冊眼科_第一篇、眼科_寅、斜弱視 Page 167-184.
- d. 交替遮蓋測試(alternate cover test):干擾雙眼融合機制,應於遮蓋-去遮蓋 測試之後再做。測試方法請為病人注視正前方物體,檢查者迅速交替遮蓋被 測者雙眼。如先遮蓋右眼數秒後,再將遮蓋物換到左眼遮蓋,同時觀察右眼 是否有移動,若右眼不動,即為正位眼;若右眼轉動,可能為斜視或隱斜視。 並以同樣方法測試左眼。 Source: 醫(六)第2冊眼科_第一篇、眼科_寅、斜弱視 Page 167-184.
- e. 稜鏡遮蓋測試(prism cover test): 稜鏡放在一眼前面且稜鏡的基底(base)朝向偏移的反方向(如測外斜視時將稜鏡基底朝向鼻側)。接著做輪流遮蓋檢查,若眼球有移動,則增加稜鏡度數,直到眼球不再移動為止。此時的稜鏡度數即為斜視的角度,可以正確測量偏移的角度。一個稜鏡度數指在一公尺處位移一公分。 Source: 醫(六)第2冊眼科_第一篇、眼科_寅、斜弱視 Page 167-184.
