# Concepts Index

Mechanisms, definitions, and frameworks.

- [[concepts/revascularization|Revascularization (血管再暢通)]] - 以 PCI 或 CABG 改善冠狀動脈血流。

- [[concepts/smoking-cessation|Smoking cessation (戒菸)]] - 心血管與肺部疾病最重要的風險修正之一。
