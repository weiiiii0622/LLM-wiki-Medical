# Conductive hearing loss (傳導性聽損)

## Summary

傳導性聽損源自外耳或中耳傳音障礙，常見於 cerumen、otitis media、otosclerosis 或 ossicular disease。 本頁已整合至 `醫(六)第4冊麻醉耳鼻喉`；若同一 topic 也出現在舊來源，來源與重點會保留並合併。

## Key Details From Sources

- (b) 若骨導比氣導時間長(BC > AC),則稱為林內試驗陰性。表示患者氣體 傳導出現異常,為傳導性聽力障礙。 Source: 醫(六)第4冊麻醉耳鼻喉_第二篇、耳鼻喉科_甲、耳科 Page 133-184.
- (b) 傳導性聽力障礙:因為氣導有抵消骨導的作用,所以具傳導性聽力障礙 的患者,其患側耳氣導出現障礙,無法抵消骨傳導,因此患側耳的骨傳 導要比健耳強,此聽到的聲音會偏向患側耳。 Source: 醫(六)第4冊麻醉耳鼻喉_第二篇、耳鼻喉科_甲、耳科 Page 133-184.
- | | Rinne test (比較單耳氣骨導) | Weber test (比較兩耳骨導) | |---------|-------------------------|---------------------| | 傳導性聽力障礙 | Negative (AC $\leq$ BC) | 偏向患側耳 | | 感音性聽力障礙 | Positive (AC > BC) | 偏向健側耳 | Source: 醫(六)第4冊麻醉耳鼻喉_第二篇、耳鼻喉科_甲、耳科 Page 133-184.
