# Febrile seizure (熱痙攣)

## Summary

發燒相關兒童癲癇發作，需區分 simple 與 complex 並排除 CNS infection。 本頁已整合至 `醫(四)第4冊神內`；若同一 topic 也出現在舊來源，來源與重點會保留並合併。

## Key Details From Sources

- (4) 熱痙攣 (febrile convulsion): 常發生於小孩 6 個月~6 歲,因為腦部發育未穩定, 一發燒就產生痙攣。屬於良性的疾病,給予塞劑退燒即可,長大後就會改善了。 Source: 醫(四)第4冊神內_乙、癲癇 Page 49-66.
- | (D) 16. 下列關於簡單型熱痙攣(simple febrile seizure)之敘述,何者錯誤? | 105( 二 ) 專醫四 -52 | |------------------------------------------------------------------|----------------------| | (A)於一歲以前發作者,易再發 | | | (B) 與將來是否智能不足無關 | | | (C) 與將來是否有行為異常無關 | | | (D) Source: 醫(四)第4冊神內_乙、癲癇 Page 49-66.
- (A) 最可能的診斷為熱性痙攣 (febrile seizure) Source: 醫(四)第4冊神內_乙、癲癇 Page 49-66.
- c. 但嬰兒玫瑰疹發燒常見熱性痙攣(febrile seizure),為良性,原因為幼兒腦細胞的發育還不完全,故高燒時容易引起腦細胞之間亂放電進而造成四肢突發性的抽筋,手腳會對稱性抽動,多半持續二到三分鐘,常引起家長的擔憂。 Source: 醫(四)第2冊皮膚_乙、感染性皮膚病 Page 19-66.
- (2) 約30~50% 病童往後會再有熱痙攣發作,只有少數病童會有較多次數發作。 Source: 醫(四)第1冊小兒_戊、神經系統性疾病 Page 229-284.
- (3) 若有以下情形,則往後再出現熱痙攣的機率會增加:9個月以下發生熱痙攣、 有家族史、先前已存在神經疾病等。 Source: 醫(四)第1冊小兒_戊、神經系統性疾病 Page 229-284.
- (4) 只有少部份以後可能會發展為癲癇,特別是複雜性熱痙攣或有神經發展異常者。 Source: 醫(四)第1冊小兒_戊、神經系統性疾病 Page 229-284.
- 通常39℃以下不需要積極退燒,除非有發紺性心臟病,慢性肺病,糖尿病或其他 代謝性疾病,或熱痙攣的患者,則是超過38℃就可考慮退燒。 Source: 醫(四)第1冊小兒_丁、感染科學 Page 165-228.
