# Sentinel lymph node biopsy, SLNB (前哨淋巴結切片)

## Summary

乳癌腋下分期程序，可降低完整腋下廓清造成的淋巴水腫與神經肩部併發症。 本頁已整合至 `醫(五)第3冊腎外小腸外肝膽胰外乳外`；若同一 topic 也出現在舊來源，來源與重點會保留並合併。

- [[sources/med5-book3-ch24]]

## Key Details From Sources

- (b) 淋巴結摘除 (sentinel lymph node biopsy): high grade 的 DCIS 必須考慮有 invasive cancer 的可能性,考慮加作 sentinel lymph node biopsy。 Source: [[sources/med5-book3-ch24|丁、乳癌]].
- 【 詳解 】 若為 DCIS 僅 做 partial mastectomy 即 可, 若為 high grade 則加做 sentinel lymph node biopsy。 Source: [[sources/med5-book3-ch24|丁、乳癌]].
- (B) 王小姐除了 DCIS 外,也有合併侵襲性癌(invasive carcinoma) 的可能,手術可以選擇加入前哨淋巴結(sentinel node)切片 手術 Source: [[sources/med5-book3-ch24|丁、乳癌]].
