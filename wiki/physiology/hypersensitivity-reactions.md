# Hypersensitivity reactions (過敏反應分類)

## Summary

Gell-Coombs hypersensitivity 分類連結 IgE、抗體、免疫複合物與 T cell-mediated 反應。 本頁已整合至 `醫(六)第4冊麻醉耳鼻喉`；若同一 topic 也出現在舊來源，來源與重點會保留並合併。

- 3. 改良型頸部廓清術(MRND) - (1) Level I 至 V 之頸部淋巴結全切除。 - (2) 與 RND 之差別在於 MRND 有保留 SCM 或 IJV 或 spinal accessory nerve (可以是任何組合)。MRND 又可再分成: - a. Type I:保留 spinal accessory nerve (SAN)。 - b. Type II: 保留 SAN+IJV。 - c. Type III:保留 SAN+IJV+SCM(故又稱為 functional neck dissection)。 Source: 醫(六)第4冊麻醉耳鼻喉_第二篇、耳鼻喉科_丁、頭頸科 Page 231-254.
- (1) 第一鰓裂異常 (First BAs): - a. 少見,又分 Type I 和 Type II。 - b. 位於 mandible angle, 顏面神經旁。 - c. 開口於外耳道。 Source: 醫(六)第4冊麻醉耳鼻喉_第二篇、耳鼻喉科_丁、頭頸科 Page 231-254.
- (2) 第二鰓裂異常 (Second BAs): - a. 最常見佔 90~95%,分 Type I, II, III, IV。 - b. 位於胸鎖乳突肌之前,穿過第十二對舌下神經(hypoglossal nerve)與第九對舌咽神經(glossopharyngeal nerve)之上,穿過內頸動脈與外頸動脈之間。 - c. 開口於扁桃腺窩 tonsillar fossa。 Source: 醫(六)第4冊麻醉耳鼻喉_第二篇、耳鼻喉科_丁、頭頸科 Page 231-254.
- 2. 依據 WHO 1978 年的分類法, , 將鼻咽癌分成以下不同類型: - (1) 角化鱗狀細胞癌 Keratinizing squamous cell carcinoma (WHO Type I): 預後最差。 - (2) 未角化癌 Nonkeratinizing carcinoma: - a. 又分成兩個亞群分別是 differentiated (Type II) 和 undifferentiated (Type III)。 - b. Type III 未分化癌(undifferentiated carcinoma)與 EBV 的感染最有關係,也是預後最好的類型。 Source: 醫(六)第4冊麻醉耳鼻喉_第二篇、耳鼻喉科_戊、頭頸部癌症 Page 255-294.
- Type I 也可稱為耳膜成形術 (Myringoplasty), 僅限於修補耳膜。 Source: 醫(六)第4冊麻醉耳鼻喉_第二篇、耳鼻喉科_甲、耳科 Page 133-184.
- Type II 使用在病患 malleus 嚴重受損時,耳膜移植物直接和 incus 相連接。 Source: 醫(六)第4冊麻醉耳鼻喉_第二篇、耳鼻喉科_甲、耳科 Page 133-184.
- Type III 的耳膜移植物會直接與 stapes 相接。 Source: 醫(六)第4冊麻醉耳鼻喉_第二篇、耳鼻喉科_甲、耳科 Page 133-184.
- 1. 定義:由於接觸外來的抗原引起 IgE-mediated hypersensitivity 反應而造成的鼻炎。 急性的過敏性鼻炎可能發生於季節變換,又稱季節性鼻炎;慢性的過敏性鼻炎則常 常是持續多年的症狀,又稱常年性鼻炎。 Source: 醫(六)第4冊麻醉耳鼻喉_第二篇、耳鼻喉科_乙、鼻科 Page 185-214.
- (6) 手術治療:針對長期發炎,合併有鼻甲肥大,造成持續性鼻塞或合併鼻中膈彎曲症狀,手術的方式有三種: - a. 鼻甲切除術 / 鼻中膈鼻道成型手術: 將肥厚的鼻甲切除,同時矯正鼻中膈,以改善呼吸通道,而鼻甲面積減少, 也有助於減少過敏反應。 - b. 鼻黏膜燒灼術: 可使用電極刀、雷射刀或化學藥物燒灼鼻黏膜,使鼻黏膜縮小。手術簡便, 適合懼怕開刀的患者。 Source: 醫(六)第4冊麻醉耳鼻喉_第二篇、耳鼻喉科_乙、鼻科 Page 185-214.
- 1. 由於鼻部副交感神經系統受刺激而造成鼻黏膜血管擴張之過敏反應,臨床上症狀與 過敏性鼻炎類似,但若沒有懷疑的過敏原或過敏史,則歸類為血管運動性鼻炎。 Source: 醫(六)第4冊麻醉耳鼻喉_第二篇、耳鼻喉科_乙、鼻科 Page 185-214.
- 2. 造成中風後肩膀疼痛的原因包括肩關節半脫位(subluxation)、肩關節囊炎、複雜性區域疼痛症候群第一型(Complex Regional Pain Syndrome Type I, CRPS Type I 或稱 Reflex SympatheticDystrophy, RSD)、旋轉肌肌腱損傷、肌肉張力太強,而可能同時有兩種以上因素,造成患者肩膀疼痛。 Source: 醫(六)第3冊復健_甲、神經復健(神內) Page 13-50.
- 3. 複雜性區域疼痛症候群第一型(Complex Regional Pain Syndrome Type I): - (1) 又名反射性交感神經失養症(RSD)或肩手症候群(shoulder-hand syndrome),造成原因不明,外傷為主要原因,其他像是中風、心肌梗塞、周邊神經損傷、惡性腫瘤等等原因都有可能。發生於 12~25% 的中風半側偏癱患者。 - (2) 在臨床表現上會出現五種主要症狀: (a) 疼痛、(b) 腫脹、(c) 自主神經失調、(d) 運動方面不協調、(e) 皮膚會變薄發亮,毛髮、指甲粗厚,肌肉萎縮。 - (3) 分期 Source: 醫(六)第3冊復健_甲、神經復健(神內) Page 13-50.
- 4. 肩關節半脫位:指上臂肱骨與肩關節盂間位移增加,因而直接造成疼痛,或因間接造成 CRPS type I 及旋轉肌肌腱損傷,進而疼痛。 Source: 醫(六)第3冊復健_甲、神經復健(神內) Page 13-50.
- ① 表現為角膜基質的圓盤狀水腫,發炎區域的內皮細胞上常有角膜沉積物 (KP) 和虹膜的發炎反應。可能與角膜對病毒抗原的遲緩型過敏反應(delayed type hypersensitivity) 有關。 Source: 醫(六)第2冊眼科_第一篇、眼科_戊、角膜 Page 53-70.
- 3. 季節性過敏性結膜炎(Seasonal allergic conjunctivitis, SAC)、常年性過敏性結膜炎(Perennial allergic conjunctivitis, PAC): 前者通常是指對植物的花粉或孢子過敏所引起之結膜發炎,常出現在特定花粉或孢子濃度升高的季節,病患本身常有氣喘,過敏性鼻炎等病史。後者則是因為對家塵(house dust mites)、黴菌、寵物等漂浮物過敏所引起。兩者皆為第一型過敏反應,發作常為短暫性或陣發性,且很少造成視力上的影響。 Source: 醫(六)第2冊眼科_第一篇、眼科_丁、結膜 Page 43-52.
- 1. 瘢痕性類天疱瘡(Ocular cicatricial pemphigoid): - (1) 簡介:第二型過敏反應,自體抗體攻擊基底膜,與 HLA-DR4、DR2 相關。 - (2) 臨床症狀: 反覆性結膜炎、結膜下水疱、結膜皺縮、乾眼、瞼球黏連 (symblepharon)、瞼瞼黏連 (ankyloblepharon),導致眼球活動受限。 - (3) 治療:口服類固醇或眼球局部使用類固醇或維他命 A 藥膏,嚴重的用口服 cyclophosphamide $1.5\sim2.0$ mg/kg/day。 Source: 醫(六)第2冊眼科_第一篇、眼科_丁、結膜 Page 43-52.
